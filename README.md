# Minesweeper

## Description
While taking Computer Science 1, I wanted additional practice with the C language and CS1 related topics such as DMA, structs, linked lists, and recursive flood-fill. 
To get this practice, I put together this simple Minesweeper game.

## Features

- **Customizable board-size**
- **Dynamic bomb generation based on board-size**
- **Linked-List based coordinate tracking for randomized bombs**
- **Recursive flood-fill driven revealing of adjacent zero-valued tiles**
